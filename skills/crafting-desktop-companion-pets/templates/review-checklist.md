# DesktopCompanion Pet Review Checklist

## Nangong Wan quality baseline

- [ ] The Nangong Wan quality standard was read before planning or major repair.
- [ ] Its decision order, gates, causal repair, long-use calibration, and stopping logic were applied.
- [ ] This character's identity, actions, effects, frames, timing, distance, weights, and cooldowns were independently derived.
- [ ] Historical Nangong Wan numbers were used only as labeled calibration evidence.

## Scope and evidence

- [ ] Exact package directory/new-package scope and immutable comparison set are recorded.
- [ ] Exact character era, form, costume, and exclusions are locked.
- [ ] Evidence ledger separates observation, historical supplement, inference, and prohibited material.
- [ ] Every effect's caster and vocabulary are verified.
- [ ] New package/migration has post-research format confirmation.

## Portfolio and pilots

- [ ] Runtime minimum is satisfied without treating it as the quality target.
- [ ] Every selected action fills a distinct portfolio role.
- [ ] Each action has a complete contract and maturity.
- [ ] Every planned risk class has a passed representative pilot.
- [ ] High-ambiguity evidence/effects or multi-risk batches received a fresh-context second review, or the limitation is recorded.
- [ ] Long/unattended batch scope, checkpoints, and stop boundary are stable.
- [ ] Candidate/retry/time budgets and forced-stop rules are recorded.

## Visual production

- [ ] Identity master passes actual-size review.
- [ ] Semantic key poses precede intermediates.
- [ ] Interpolation is limited to structurally stable intervals.
- [ ] Prop and effect lifecycles are complete.
- [ ] Approved body scale is preserved independently from effect extent.
- [ ] Intentional body motion is preserved; unwanted drift is removed.
- [ ] Alpha, slicing, registration, cell order, and atlas assembly are deterministic.
- [ ] Contact sheet, true-duration preview, checker/light/dark renders, and actual-size views pass.

## Runtime and behavior

- [ ] Selected schema and current format documentation pass.
- [ ] WebP dimensions, decode, alpha, cells, mappings, Registry, and Catalog pass.
- [ ] Menu/manual labels and action playback pass.
- [ ] Automatic eligibility, weights, cooldowns, groups, and observed distribution pass.
- [ ] Weighted regimes use recorded seeds and enough simulated choices for at least 100 expected selections of the rarest eligible candidate.
- [ ] Direction, world-motion frames, screen-relative distance, and edge behavior pass.
- [ ] Interruption, recovery, return to idle, forms/sequences/restoration pass as applicable.
- [ ] Installed runtime/log check is completed only when authorized.

## Long-use and handoff

- [ ] Normal-scale desktop soak records duration, settings, event counts, backgrounds, displays, and build hashes.
- [ ] No blocking repetition, dominance, invisible rarity, edge stall, interruption, or recovery defect remains.
- [ ] Provenance, selection, maturity, and user acceptance scope are not conflated.
- [ ] Packaging status is independent from maturity and release authority.
- [ ] Upstream edits invalidate and rerun affected downstream maturity claims.
- [ ] Exact commands, exit codes, hashes, visual artifacts, limitations, and release status are recorded.
- [ ] Integration, installation, commit, push, publication, and release authority are separately confirmed where used.
- [ ] Local-only keep/archive/cleanup/uncertain inventory is reported without deletion.
