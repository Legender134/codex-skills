# Review Checklist Route

Use this retained human route before a gate review or handoff. Record each
visual decision in [Visual verdict](visual-verdict.json) and the final
maturity, authority, unverified checks, and local-state inventory in [Run
summary](run-summary.json).

Read [Visual QA](../references/visual-qa.md) for source through behavior gates,
[Canonical Identity and
Proportions](../references/canonical-identity-and-proportions.md) for
actual-size identity selection, [Repair and
Convergence](../references/repair-and-convergence.md) for failed gates, and
[Behavior and Soak](../references/behavior-and-soak.md) for long-use review.

This Markdown route intentionally does not duplicate JSON field definitions.
