# Compatibility Route

This retained path is not the normative workflow.

| Need | Read |
|---|---|
| New package or migration capability decision | [Project brief](../templates/project-brief.md) |
| Existing fixed 8×11 package or confirmed fixed-grid route | [Format v2](format-v2.md) |
| Single dynamic transparent-atlas route | [Format v3](format-v3.md) |
| Layers, forms, transformations, sequences, or bucket behavior | [Format v4](format-v4.md) |
| Technical, visual, package, Registry/Catalog, or launched-runtime gate evidence | [Visual QA](visual-qa.md) |
| Runtime scheduler, movement, or long-use policy | [Behavior and Soak](behavior-and-soak.md) |

Use the caller-supplied current runtime source for version authority; a schema
pass never substitutes for runtime or visual acceptance.
