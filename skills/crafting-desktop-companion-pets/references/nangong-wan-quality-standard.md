# Compatibility Route

This retained path is not the normative workflow.

| Need | Read |
|---|---|
| Nangong Wan process transfer or historical record | [Nangong Wan Calibration Case](nangong-wan-calibration-case.md) |
| Target identity, evidence, or conflict | [Identity and Evidence](identity-and-evidence.md) |
| Canonical identity or actual-size proportion review | [Canonical Identity and Proportions](canonical-identity-and-proportions.md) |
| Action portfolio, effects, movement, or recovery | [Actions and Motion](actions-and-motion.md) |
| Visual or runtime gate evidence | [Visual QA](visual-qa.md) |
| Causal repair, behavior, soak, or stopping | [Repair and Convergence](repair-and-convergence.md) and [Behavior and Soak](behavior-and-soak.md) |

The Nangong Wan case calibrates process, not another pet’s numerical parameters.
